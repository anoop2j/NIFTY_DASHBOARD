NIFTY100 / ETF Multi-Screener Dashboard

A single self-contained HTML dashboard, generated by one Python script (multi_screener.py), that screens the NIFTY 100 universe and a custom ETF list every day and publishes the results as a static webpage (docs/index.html) — no server, database, or backend required.

The script downloads daily OHLCV data from Yahoo Finance (yfinance), runs six independent screens against it, and writes everything into one HTML file you can open locally, host on GitHub Pages, or view straight from docs/index.html.

Tabs / Screens

The dashboard has six tabs. Each one is an independent strategy — a stock can appear on more than one tab, or on none at all.

1. MWD (Monthly · Weekly · Daily)

Looks for stocks where the trend is aligned bullish across three timeframes at once:

Today's daily candle is bullish
The current (still-forming) week is bullish
The last fully completed week was bullish
The last fully completed month was bullish

Only shows stocks that are below their 52-week high (not already there), and reports how far away the price is from that high, plus the current month's % rise so far.

2. SST (20-Day-Low Swing Setup)

Tracks every stock's current distance from its own rolling 20-day high, alongside a historical strike rate: out of every past cycle that started at a new 20-day low, how many times did the stock go on to rally SST_TARGET% (default 6%) before making another new low? Shown as a Yes/No/Strike-rate column so you can judge how reliable the setup has historically been for that specific stock.

3. BLSH RSI (Buy-Low-Sell-High, mean reversion)

A new-low + oversold-RSI mean-reversion setup. A stock qualifies only when, on the same day:

RSI(14) is below RSI_LIMIT (default 36), and
Today's low is a new 25-day low

For qualifying stocks it computes a Trigger price (BLSH_TRIGGER_PCT, default 6.5%, above the 25-day low) and a Target price (BLSH_TARGET_PCT, default 3.14%, above the trigger) — a two-stage bounce play off an oversold low.

4. ETF 28 SMA

An entry/exit signal for ETFs based on their 28-day SMA:

Entry — 2 consecutive closes above the 28 SMA
Exit — 2 consecutive closes below the 28 SMA

Also shows the current above/below streak length, and filters out illiquid ETFs whose average daily traded value (20-day lookback) is below ETF_MIN_ADV_CR crore.

5. CAR — Cumulative Average from 52-Week High

For every stock, this finds the 52-week high closing price and its date, then treats that high day as Day 1 and builds a running (cumulative) average of daily closes from Day 1 onward — so the CAR Value is simply the average closing price of every trading day from the 52-week high through today.

A stock is only shown if that cumulative average has risen continuously — every single one of the last CAR_TREND_DAYS (default 10) trading days strictly higher than the day before it, with no dips in between. This filters for stocks that made a top and have been steadily, uninterruptedly building a higher average price ever since — not just bouncing once and fading.

Each card also shows a Trigger Price: the highest daily High over the last 5 trading days (last week's high) — a breakout level to watch for an entry.

Unlike the other tabs, CAR renders as a wrapping card grid instead of a table, so it never needs a horizontal scrollbar at any screen size.

6. Upload Symbols

A utility tab for managing the two CSV symbol lists the script reads (nifty100_symbols.csv and etf_symbols.csv). Since the dashboard is a static file, it can't write back into the repo directly — this tab lets you pick a new CSV in your browser, preview it, and download a correctly-named replacement file to commit back into the project folder.

How it works
nifty100_symbols.csv ──┐
                        ├──► multi_screener.py ──► docs/index.html
etf_symbols.csv ────────┘         (yfinance)
multi_screener.py reads the symbol lists.
For each symbol, it downloads ~18 months of daily OHLCV data via yfinance (NSE symbols, suffixed .NS).
Every screen (MWD, SST, BLSH, ETF, CAR) runs independently against that data.
Matching results are sorted and rendered into one static HTML file with tabs, filters, and sortable/filterable tables or cards — no JavaScript framework, no build step.
Requirements
pip install pandas yfinance requests

Python 3.9+ (uses zoneinfo from the standard library).

Running it
python multi_screener.py

This regenerates docs/index.html. Open that file directly in a browser, or serve the docs/ folder (e.g. via GitHub Pages) to view it online. Typically this is scheduled to run once a day (e.g. via GitHub Actions / cron) after market close.

Configuration

All tunable thresholds live in clearly labelled settings blocks at the top of multi_screener.py:

Setting	Default	Controls
ETF_SMA_PERIOD	28	ETF entry/exit SMA length
ETF_ADV_LOOKBACK / ETF_MIN_ADV_CR	20 / 1.0 cr	ETF liquidity filter
SST_LOOKBACK / SST_TARGET	20 / 6.0%	SST cycle length & target
BLSH_LOOKBACK	25	BLSH new-low lookback
BLSH_TRIGGER_PCT / BLSH_TARGET_PCT	6.5% / 3.14%	BLSH trigger & target
RSI_PERIOD / RSI_LIMIT	14 / 36	BLSH oversold RSI filter
ANALYSIS_DAYS	252	Trading days treated as "52 weeks"
CAR_MIN_DAYS	10	Minimum trading days since the 52-week high before a stock is evaluated
CAR_TREND_DAYS	10	Consecutive trading days the CAR value must rise, with no dips
Notes on "days" throughout the dashboard

Every "days since" or lookback figure in this dashboard counts trading days — days on which the stock actually traded and has a closing price — never calendar days. Weekends and market holidays are never counted.
