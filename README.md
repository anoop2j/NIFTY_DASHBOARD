# 📊 Nifty 100 Daily Multi-Screener

A Python-based stock screening dashboard for **Nifty 100 stocks**, automatically updated daily using GitHub Actions and displayed through GitHub Pages.

The dashboard combines three different technical screeners into a single responsive web page:

1. 📈 MWD – Monthly + Weekly + Daily Bullish Screener
2. 🚀 SST – 20-Day High Breakout Screener
3. 📉 BLSH RSI – RSI Oversold + 25-Day Low Screener
